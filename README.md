# 🛒 Maven Toys Sales Performance Dashboard

> An end-to-end Business Intelligence project built with **Power BI**, **Power Query**, and **DAX** to analyze sales performance, revenue, profit, and business trends.

---

# 📖 Project Overview

This project demonstrates the complete Business Intelligence workflow using Power BI, from connecting raw CSV files to building an interactive sales dashboard for business decision-making.

The dashboard provides insights into sales performance across products, stores, and time while showcasing best practices in data modeling, DAX calculations, and dashboard design.

---

# 🎯 Project Objectives

## 📌 Data Preparation

- Connected Sales, Products, Stores and Calendar datasets
- Reviewed data quality
- Checked null and blank values
- Validated data types
- Identified primary and foreign keys
- Created Start of Month column
- Created Start of Week column

---

## 📌 Data Modeling

Designed a Star Schema model by:

- Creating one-to-many relationships
- Building a Date Hierarchy
- Connecting all dimension tables
- Hiding unnecessary foreign keys

---

## 📌 Data Enrichment

Created calculated columns for:

- Product Cost
- Product Price
- Revenue
- Profit

Created DAX measures for:

- Total Orders
- Total Revenue
- Total Profit

---

## 📌 Dashboard Development

Designed an interactive dashboard including:

- KPI Cards
- Revenue Trends
- Profit Trends
- Orders Trend
- Product Category Analysis
- Store Location Filter
- Interactive Slicers
- Time Intelligence
